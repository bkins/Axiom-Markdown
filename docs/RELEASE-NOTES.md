# Axiom Markdown 0.1.0 review

First separate Markdown-focused edition derived from Axiom 1.9.0. Retains Markdown editing/preview and recovery, HTML/DOCX import and six export formats, Git/history, terminal and the separate update client. Removes CP/AI, semantic analysis, classification/relationship management and the larger personal knowledge-management shell.

Adds user and machine-policy controls for retained optional features, visible sanitization notices/details, blocked-by-default remote images with destination/session approval, a data-only document preview and separate application/state/installer/feed identities. This unsigned review build still needs Ben's usability review and organizational security/deployment approval.
